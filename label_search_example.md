# Система поиска по меткам

## Описание
Система должна искать не только по словам, но также и по меткам. При поиске задания для 10 класса по химии, система должна учитывать следующие метки:

## Пример меток
- **Класс**: 10
- **Предмет**: Химия  
- **Тема**: Без темы

## Структура меток в данных
```
{
  "title": "Задание для 10 класса по химии",
  "labels": {
    "class": "10",
    "subject": "Химия",
    "topic": "Без темы"
  },
  "content": "Текст задания..."
}
```

## Алгоритм поиска
1. При получении запроса "задание для 10 класса по химии" система анализирует его на предмет указания класса и предмета
2. Система формирует поисковый запрос по меткам: class:"10" AND subject:"Химия"
3. Система возвращает все материалы, соответствующие этим меткам
4. Дополнительно можно применить фильтрацию по другим меткам (например, тема, сложность и т.д.)

## Преимущества поиска по меткам
- Более точные результаты поиска
- Возможность гибкой фильтрации материалов
- Упрощение навигации по большому объему учебных материалов
- Возможность создания комплексных поисковых запросов через комбинацию меток
